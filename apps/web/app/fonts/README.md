# Fonts

Self-hosted latin subsets, downloaded from Google Fonts on 2026-11-12 and loaded with `next/font/local` in `app/layout.tsx`. All three families are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org).

| File                            | Family                   | Source                                                                        |
| ------------------------------- | ------------------------ | ----------------------------------------------------------------------------- |
| `geist.woff2`                   | Geist (variable 100–900) | [vercel/geist-font](https://github.com/vercel/geist-font)                     |
| `geist-mono.woff2`              | Geist Mono (variable)    | [vercel/geist-font](https://github.com/vercel/geist-font)                     |
| `instrument-serif.woff2`        | Instrument Serif Regular | [Instrument/instrument-serif](https://github.com/Instrument/instrument-serif) |
| `instrument-serif-italic.woff2` | Instrument Serif Italic  | [Instrument/instrument-serif](https://github.com/Instrument/instrument-serif) |
